Referencias para ChatGPT

Junta las imágenes que más te gustan en colecciones y prepáralas para subirlas a ChatGPT como referencia.

 
  • Abrir esto: npm run imagenes en la carpeta del proyecto.
  • Si llegaron imágenes nuevas a elegida/: npm run imagenes:actualizar y recarga.
  • Pasar las elecciones a la página: npm run imagenes:aplicar (prueba) y después npm run imagenes:aplicar -- --write.
  • Las referencias preparadas quedan en output/referencias-chatgpt/, una carpeta por colección.
